# No-deployment boundary

This corrective branch is code/review work only.

Do not deploy it, start or restart the VM/service, enable a wallet, enable authenticated
CLOB order APIs, or treat its paper results as validated strategy evidence merely
because repository tests pass.

A later deployment requires an explicitly authorized acceptance step with installed
unit/process/import/config identity attestation, paper database backup/restore proof,
and a fresh independent adversarial review of the frozen candidate SHA.
